Sobre

Quem está por trás do código

Sou estudante de Engenharia de Software na UNINTER e estou em busca do meu primeiro estágio em desenvolvimento de software. Enquanto curso a faculdade, trabalho em tempo integral e uso meu tempo livre para construir projetos de verdade — do front-end ao deploy — porque acredito que a melhor forma de aprender é entregando.

Gosto de código limpo, de entender o problema antes de sair programando e de fazer coisas que funcionam de fato para quem vai usar. Hoje trabalho melhor com JavaScript e TypeScript, React e Next.js, e estou me aprofundando em Java por meio de cursos e bootcamps.

Da minha experiência profissional em ambientes operacionais trago disciplina, comunicação clara e o hábito de treinar e apoiar colegas — habilidades que levo comigo para qualquer time.

CodeSplain IA

Aplicação full stack que gera explicações de código em linguagem simples para quem está começando a programar. O usuário cola um trecho de código, escolhe a linguagem e recebe uma explicação didática em português gerada por IA. Inclui prompt de sistema fixando as respostas em PT-BR e retry automático quando a API responde com limite de requisições (429).

  • React 19
  • Vite
  • TailwindCSS
  • Node.js
  • Express
  • REST API
  • Integração com LLM
